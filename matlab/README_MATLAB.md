# MATLAB/Simulink Integration

## Requirements
- MATLAB R2021b or later
- Simulink
- Simscape Electrical (for microgrid model)
- Instrument Control Toolbox (for `tcpclient`)

## Setup

1. **Start the Python co-simulation bridge first:**
   ```bash
   python3 src/cosimulation/matlab_bridge.py checkpoints/best_model.pt
   ```
   The bridge binds to `127.0.0.1:5760`.

2. **Open the Simulink model** (not included — build per Section IV-A of the paper).

3. **Add a MATLAB Function block** to your Simulink model and paste the
   contents of `simulink_tcp_client.m` (auto-generated by the bridge on first run).

4. **Connect block inputs/outputs:**
   | Simulink signal | Block input/output |
   |---|---|
   | Bus voltage (V) | `v` |
   | Grid frequency (Hz) | `f` |
   | Active power (W) | `p` |
   | Reactive power (VAR) | `q` |
   | BESS SoC (%) | `soc` |
   | Solar irradiance (W/m²) | `irr` |
   | PV setpoint (kW) | `pv_kw` |
   | BESS setpoint (kW) | `bess_kw` |
   | Diesel setpoint (kW) | `diesel_kw` |

5. **Set simulation step size** to 0.1 s (10 Hz) to match IEC 61850 sampling.

## Microgrid Model Parameters

| Component | Rating |
|---|---|
| PV Solar Array | 50 kW peak |
| BESS (Li-ion) | 30 kW / 100 kWh |
| Diesel Generator | 40 kW |
| Nominal Bus Voltage | 480 V (3-phase) |
| Nominal Frequency | 60 Hz |
| Load | 80 kW (mixed R/L) |

## Attack Injection

To inject attacks during simulation, use MATLAB workspace variables:
```matlab
% FDI: voltage bias injection
set_param('microgrid/FDI_Injector','Value','1')

% DoS: communication delay block
set_param('microgrid/DoS_Block','DelayTime','0.5')
```
